OOP 基础专名。

## 对象与类

### Object

- **中文**：对象
- 数据（状态）与相关行为的打包实例；由 Class 构造。

### Class

- **中文**：类
- 对象的蓝图：定义字段与方法（统称 members）。

### Superclass

- **中文**：超类
- 继承层次中的父类。

### Subclass

- **中文**：子类
- 继承并扩展超类；可覆盖（override）方法。

### Interface（OOP）

- **中文**：接口（契约）
- 对象对外可交互的公开部分；语言里的 `interface` / `protocol` 类型用行为契约描述协作，通常不含字段。勿与「对象的 public 表面」一词混淆。

## 四大支柱

### Abstraction

- **中文**：抽象
- 在特定上下文中建模真实事物：保留相关细节、省略其余。同一现实对象在不同应用中模型不同。

### Encapsulation

- **中文**：封装
- 隐藏内部状态与行为，只暴露有限接口（private / protected 等）。

### Inheritance

- **中文**：继承
- 在已有类上构建新类以复用；子类通常与父类共享接口，多数语言单继承、可多实现接口。

### Polymorphism

- **中文**：多态
- 在只知道父类型 / 接口时，运行时仍调用到具体子类实现。

## 关系

### Dependency

- **中文**：依赖
- 最弱关系：一处定义变更可能迫使另一处修改（签名、构造具体类等）。依赖接口可减弱。

### Association

- **中文**：关联
- 对象知道并使用另一对象；链路通常持久（如字段），是带「长期引用」的依赖。

### Aggregation

- **中文**：聚合
- 特殊关联：整体「拥有」部分集合；部分可独立存在、可属于多个容器（空心菱形）。

### Composition

- **中文**：组合（强聚合）
- 部分只作为整体的一部分存在，生命周期由整体管理（实心菱形）。口语「组合优于继承」里的 composition 常泛指对象组合（含聚合）。
