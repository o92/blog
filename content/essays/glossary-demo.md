悬停下方加下划线的词，会出现解释气泡。点气泡里的 **显示更多** / **外部链接** 可跳转。

## 站内跳转（显示更多）

把鼠标移到 **goroutine** 上，再点「显示更多」——应跳到《Go 并发笔记 → 简介 → 阅读方式》。

再试一次：**Go**（跳到「这本书讲什么」）。

## 外链跳转

悬停 **channel**，点「外部链接」——应打开 Go 语言规范。

悬停 **Hugo**，点「外部链接」——应打开 Hugo 官网。

## 仅说明、无跳转

**术语** 只有摘要，没有「显示更多」。

## 不应高亮

代码块里的词不应出现气泡：

```go
go func() { /* goroutine in code */ }()
```

行内 `channel` 也不应高亮。
