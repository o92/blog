**英文标题**：Partial responses  
**原文**：[AIP-157](https://google.aip.dev/157) · approved · 创建 2019-01-26

资源有时很大，或者算起来很贵。API 需要让用户控制：这次回哪些字段。

API 可以用两种方式支持部分响应。

## 字段掩码参数

Field masks（`google.protobuf.FieldMask`）给用户细粒度控制：回哪些字段。API 应当在旁路里支持该 mask。例如：HTTP query parameter、HTTP header，或 [gRPC metadata entry](https://grpc.io/docs/what-is-grpc/core-concepts/#metadata)。Google Cloud APIs 把 field masks 指定为 [system parameter](https://cloud.google.com/apis/docs/system-parameters)。

Field masks 不应当在[请求字段](#请求字段上的-read-mask)里指定。

- field mask 参数的值必须为 `google.protobuf.FieldMask`。
- field mask 参数必须是可选的：
  - 应当支持显式值 `"*"`，并且它必须返回所有字段。
  - 若省略 field mask 参数，必须默认为 `"*"`，除非另有文档。
- API 可以允许带非终端 repeated 字段的 read masks（和 update masks 不同），但没有义务这样做。

更改 field mask 参数的默认值是破坏性变更（见 [AIP-180]({{< ref "aip-0180" >}})）。

## View 枚举

或者，API 可以用 view enums 支持部分响应。适合 API 只想向用户暴露少量固定排列的情形：

```proto
enum BookView {
  // The default / unset value.
  // The API will default to the BASIC view.
  BOOK_VIEW_UNSPECIFIED = 0;

  // Include basic metadata about the book, but not the full contents.
  // This is the default value (for both ListBooks and GetBook).
  BOOK_VIEW_BASIC = 1;

  // Include everything.
  BOOK_VIEW_FULL = 2;
}
```

- enum 应当作为请求 message 上的 `view` 字段。
- enum 应当命名为以 `-View` 结尾的某种名称。
- enum 应当至少有名为 `BASIC` 与 `FULL` 的值（也可以有这些以外的值）。
- `UNSPECIFIED` 值必须有效（不是错误），并且 API 必须文档化未指定值会做什么。
  - 对 List RPC，有效默认值应当为 `BASIC`。
  - 对下列 RPC 类型，有效默认值应当为 `BASIC` 或 `FULL`：
    - Get
    - Create
    - Update
    - Soft Delete
    - Custom Method
- enum 应当定义在 proto 文件的顶层（Get 与 List 等多处请求都会用到）。顶层枚举见 [AIP-126]({{< ref "aip-0126" >}}）。
- API 可以随时间向给定 view 添加字段。不得从给定 view 移除字段（这是破坏性变更）。

若服务需要（或可能需要）多个值重叠但不同的 views，会有命名空间冲突。这时应当把 view enum 嵌套在个别资源内。

让部分响应成为标准方法的默认，可能降低声明式客户端的有效性。若认为部分响应有必要，更好的做法是提供「请求在响应中填充完整资源」的机制，例如本 View 模式。

## 请求字段上的 read mask

**Warning:** 作为请求 message 上单个显式字段的 read mask，对 Google APIs **已废弃**。必须改用[字段掩码参数](#字段掩码参数)那种 system parameter。下列指导只为现有遗留 Google 与外部非 Google 用法保留。

API 可以支持作为请求 message 上单个字段的 read masks：`google.protobuf.FieldMask read_mask`。

- read mask 必须为 `google.protobuf.FieldMask`，并且应当名为 `read_mask`。
- field mask 应当是可选的：
  - 应当支持显式值 `"*"`，并且它必须返回所有字段。
  - 若未提供 field mask 参数，必须返回所有字段。
- API 可以允许带非终端 repeated 字段的 read masks（和 update masks 不同），但没有义务这样做。

## 为什么这样规定

### 废弃请求 message 里的 `read_mask`

Google API 基础设施已经实现服务范围的响应字段过滤。个别 API 方法不必在请求 schema 里再写 `read_mask`。那样既冗余，也可能成为客户端或服务的冲突点。
