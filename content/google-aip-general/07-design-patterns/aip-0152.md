偶尔，APIs 可能需要暴露一项需要显著时间才能完成的任务，而瞬时的 long-running operation（[AIP-151]({{< ref "aip-0151" >}})）并不合适。例如，任务可能需要反复运行，或配置任务与运行任务有分开的权限。

## Guidance

API **may** 定义 `Job` 资源来表示一项有明确 setup、configuration 与 execution 的特定任务：

```proto
message WriteBookJob {
  option (google.api.resource) = {
    type: "library.googleapis.com/WriteBookJob"
    pattern: "publishers/{publisher}/writeBookJobs/{write_book_job}"
  };

  // Name and other fields...
}
```

- 资源名称 **must** 以单词 "Job" 结尾。
  - 前缀 **should** 为有效的 RPC 名称，带一个动词和一个名词。
- 服务 **should** 定义全部五个标准方法（[AIP-131]({{< ref "aip-0131" >}})、[AIP-132]({{< ref "aip-0132" >}})、[AIP-133]({{< ref "aip-0133" >}})、[AIP-134]({{< ref "aip-0134" >}})、[AIP-135]({{< ref "aip-0135" >}})，并把它们作为配置该 job 的主要方式。

### Run method

服务 **should** 定义一个立即执行该 job 的 `Run` custom method：

```proto
rpc RunWriteBookJob(RunWriteBookJobRequest)
    returns (google.longrunning.Operation) {
  option (google.api.http) = {
    post: "/v1/{name=publishers/*/writeBookJobs/*}:run"
    body: "*"
  };
  option (google.longrunning.operation_info) = {
    response_type: "RunWriteBookJobResponse"
    metadata_type: "RunWriteBookJobMetadata"
  };
}
```

- RPC 的名称 **must** 以单词 `Run` 开头。RPC 名称的其余部分 **should** 为正在运行的 job 资源的单数形式。
- 请求 message **must** 与 RPC 名称匹配，并带 `Request` 后缀。
- 该方法 **should** 返回 long-running operation（[AIP-151]({{< ref "aip-0151" >}})），它 **must** 解析为包含运行该 job 之结果的响应 message。
  - 响应 message 名称必须与 RPC 名称匹配，并带 `Response` 后缀。
  - 该方法 **may** 使用任何它希望的 metadata message。
- HTTP 动词 **must** 为 `POST`，与 custom methods（[AIP-136]({{< ref "aip-0136" >}})）通常一样。
- `google.api.http` annotation 中的 body 子句 **should** 为 `"*"`。
- URI 路径 **should** 包含单个对应正在运行的 job 资源名称的 `name` 变量。
- URI 路径 **must** 以 `:run` 结尾。
- 阻止 job 执行*启动*的错误 **must** 返回错误响应（[AIP-193]({{< ref "aip-0193" >}})），与任何其它方法类似。在 job 执行过程中发生的错误 **may** 放在 metadata message 中。错误本身 **must** 仍用 [`google.rpc.Status`](https://github.com/googleapis/googleapis/blob/master/google/rpc/status.proto) 对象表示。

### Run request message

Run methods 实现一种常见的请求 message 模式：

```proto
message RunWriteBookJobRequest {
  // The name of the job to run.
  string name = 1 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      type: "library.googleapis.com/WriteBookJob"
    }];
}
```

- **must** 包含单数 `string name` 字段。
  - 该字段 **should** 被标注为 required（[AIP-203]({{< ref "aip-0203" >}})）。
  - 该字段 **should** 标识它所引用的 resource type（[AIP-123]({{< ref "aip-0123" >}})）。

### Executions and results

通常，API **should** 把结果作为 `Run` 方法的最终响应提供给用户。然而，这有时不够；例如，在后台按重复调度运行的 job 无法以此方式把结果交给用户。

服务 **may** 把表示个别 executions 及其结果的资源存储为该 job 下的子集合，这允许用户列出*过去的* job executions。这样做的服务 **should** 为 execution 资源定义 `Get`、`List` 与 `Delete` 方法：

```proto
message WriteBookJobExecution {
  option (google.api.resource) = {
    type: "library.googleapis.com/WriteBookJobExecution"
    pattern: "publishers/{publisher}/writeBookJobs/{write_book_job}/executions/{execution}"
  };

  // Name and other information about the execution, such as metadata, the
  // result, error information, etc.
}
```

此时，job 的 `Run` 方法返回的 operation **should** 引用该 child resource。
