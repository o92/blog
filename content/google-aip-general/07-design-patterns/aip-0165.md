**英文标题**：Criteria-based delete  
**原文**：[AIP-165](https://google.aip.dev/165) · approved · 创建 2019-12-18 · 更新 2022-06-02  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

偶尔 API 需要按一组过滤参数删掉大量资源，而不是一个个 resource name 列出来。

这是罕见情形。留给用户一次要删数千或更多资源、常规 Batch Delete（见 [AIP-235]({{< ref "aip-0235" >}})）已经笨重不便的时候。

## 尽量不要做

大多数 API 应当只用 Delete（见 [AIP-135]({{< ref "aip-0135" >}})）或 Batch Delete（见 [AIP-235]({{< ref "aip-0235" >}})）删资源，不应当实现基于条件的删除。删除一般不可逆，这类操作很容易让用户一次丢掉大量数据。

API 可以实现 Purge 方法，按过滤字符串删除大量资源。但这应当仅在 Batch Delete 模式盖不住目标时才做：

```proto
rpc PurgeBooks(PurgeBooksRequest) returns (google.longrunning.Operation) {
  option (google.api.http) = {
    post: "/v1/{parent=publishers/*}/books:purge"
    body: "*"
  };
  option (google.longrunning.operation_info) = {
    response_type: "PurgeBooksResponse"
    metadata_type: "PurgeBooksMetadata"
  };
}
```

- RPC 名称必须以 `Purge` 开头。其余部分应当是正在 purge 的资源的复数形式。
- 请求 message 必须与 RPC 名称匹配，并带 `Request` 后缀。
- 响应类型必须是 `google.longrunning.Operation`（见 [AIP-151]({{< ref "aip-0151" >}})），解析为名称与 RPC 名称匹配并带 `Response` 后缀的 message。
- HTTP 动词必须为 `POST`，`body` 必须为 `"*"`。
- URI 路径应当表示该资源的集合。
- `parent` 字段应当包含在 URI 中。若 API 希望支持跨多个 parents 删除，应当接受与 [AIP-159]({{< ref "aip-0159" >}}) 一致的 `-` 字符。

## 请求

Purge 用一套常见的请求 message 模式：

```proto
message PurgeBooksRequest {
  // The publisher to purge books from.
  // To purge books across publishers, send "publishers/-".
  string parent = 1 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      child_type: "library.googleapis.com/Book"
    }];

  // A filter matching the books to be purged.
  string filter = 2 [(google.api.field_behavior) = REQUIRED];

  // Actually perform the purge.
  // If `force` is set to false, the method will return a sample of
  // resource names that would be deleted.
  bool force = 3;
}
```

- 应当包含单数 `string parent` 字段，除非资源是顶层资源。
  - 该字段应当标注为 required（见 [AIP-203]({{< ref "aip-0203" >}})）。
  - 该字段应当标识它所引用的 resource type（见 [AIP-123]({{< ref "aip-0123" >}})）。
- 必须包含单数 `string filter` 字段，并且必须遵循与 List 方法相同的语义（见 [AIP-160]({{< ref "aip-0160" >}})）。
  - 它应当标注为 required（见 [AIP-203]({{< ref "aip-0203" >}})）。
  - 可以支持通配符值 `"*"` 以删除一切。
- 必须包含单数 `bool force` 字段。未设置时，API 必须返回将被删除的资源计数以及那些资源的样本，而不实际执行删除。

## 响应

Purge 用一套常见的响应 message 模式：

```proto
message PurgeBooksResponse {
  // The number of books that this request deleted (or, if `force` is false,
  // the number of books that will be deleted).
  int32 purge_count = 1;

  // A sample of the resource names of books that will be deleted.
  // Only populated if `force` is set to false.
  repeated string purge_sample = 2 [(google.api.resource_reference) = {
    type: "library.googleapis.com/Book"
  }];
}
```

- 应当包含单数 `int32 purge_count` 字段，提供已删除（或将被删除）的资源数。此计数可以是类似 [AIP-158]({{< ref "aip-0158" >}}) 中 `total_size` 的估计值；若如此，服务应当文档化。
- 应当包含 `repeated string purge_sample` 字段：`force` 为 `false` 时，应当提供将被删除的 resource names 样本。`force` 为 true 时，此字段不应当被填充。
  - 样本应当足够大，能抓住明显错误：经验法则是 100。API 应当文档化该大小，并且应当文档化它是最大值（可能发得更少）。
  - 样本可以随机，也可以确定性（例如最先匹配的 resource names）。API 应当文档化用哪种。
  - 该字段应当标识它所引用的 resource type（见 [AIP-123]({{< ref "aip-0123" >}})）。

即使不包含 `purge_count` 与 `purge_sample`，请求中仍必须包含 `force` 字段。
