**英文标题**：Criteria-based delete  
**原文**：[AIP-165](https://google.aip.dev/165) · approved · 创建 2019-12-18 · 更新 2022-06-02  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

偶尔，API 可能需要提供一种机制，基于某组过滤参数删除大量资源，而不是要求被删除资源的个别 resource name。

这是罕见情形，保留给用户需要一次删除数千或更多资源的情况，此时常规 Batch Delete 模式（[AIP-235]({{< ref "aip-0235" >}})）变得笨重不便。

## Guidance

**Important:** 大多数 APIs **should** 只使用 Delete（[AIP-135]({{< ref "aip-0135" >}})）或 Batch Delete（[AIP-235]({{< ref "aip-0235" >}})）删除资源，并且 **should not** 实现基于条件的删除。这是因为删除一般不可逆，并且此类操作让用户很容易意外丢失大量数据。

API **may** 实现 Purge 方法以允许基于过滤字符串删除大量资源；然而，这 **should** 仅在 Batch Delete（[AIP-235]({{< ref "aip-0235" >}})）模式不足以完成期望目标时才做：

```proto
rpc PurgeBooks(PurgeBooksRequest) returns (google.longrunning.Operation) {
  option (google.api.http) = {
    post: "/v1/{parent=publishers/*}/books:purge"
    body: "*"
  };
  option (google.longrunning.operation_info) = {
    response_type: "PurgeBooksResponse"
    metadata_type: "PurgeBooksMetadata"
  };
}
```

- RPC 的名称 **must** 以单词 `Purge` 开头。RPC 名称的其余部分 **should** 为正在 purge 的资源的复数形式。
- 请求 message **must** 与 RPC 名称匹配，并带 `Request` 后缀。
- 响应类型 **must** 为解析为名称与 RPC 名称匹配并带 `Response` 后缀之 message 的 `google.longrunning.Operation`（见 [AIP-151]({{< ref "aip-0151" >}})）。
- HTTP 动词 **must** 为 `POST`，并且 `body` **must** 为 `"*"`。
- URI 路径 **should** 表示该资源的集合。
- `parent` 字段 **should** 包含在 URI 中。若 API 希望支持跨多个 parents 删除，它 **should** 接受与 [AIP-159]({{< ref "aip-0159" >}}) 一致的 `-` 字符。

### Request message

Purge methods 实现一种常见的请求 message 模式：

```proto
message PurgeBooksRequest {
  // The publisher to purge books from.
  // To purge books across publishers, send "publishers/-".
  string parent = 1 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      child_type: "library.googleapis.com/Book"
    }];

  // A filter matching the books to be purged.
  string filter = 2 [(google.api.field_behavior) = REQUIRED];

  // Actually perform the purge.
  // If `force` is set to false, the method will return a sample of
  // resource names that would be deleted.
  bool force = 3;
}
```

- **should** 包含单数 `string parent` 字段，除非资源是顶层资源。
  - 该字段 **should** 被 [标注为 required]({{< ref "aip-0203" >}})。
  - 该字段 **should** 标识它所引用的 [resource type]({{< ref "aip-0123" >}})。
- **must** 包含单数 `string filter` 字段，并且 **must** 遵循与 List 方法（[AIP-160]({{< ref "aip-0160" >}})）相同的语义。
  - 它 **should** 被 [标注为 required]({{< ref "aip-0203" >}})。
  - **may** 支持通配符值 `"*"` 以删除一切。
- **must** 包含单数 `bool force` 字段。若未设置，API **must** 返回将被删除的资源计数以及那些资源的样本，而不实际执行删除。

### Response message

Purge methods 实现一种常见的响应 message 模式：

```proto
message PurgeBooksResponse {
  // The number of books that this request deleted (or, if `force` is false,
  // the number of books that will be deleted).
  int32 purge_count = 1;

  // A sample of the resource names of books that will be deleted.
  // Only populated if `force` is set to false.
  repeated string purge_sample = 2 [(google.api.resource_reference) = {
    type: "library.googleapis.com/Book"
  }];
}
```

- **should** 包含单数 `int32 purge_count` 字段，并提供已删除（或将被删除）的资源数。此计数 **may** 为类似 [AIP-158]({{< ref "aip-0158" >}}) 中 `total_size` 的估计值（但若如此服务 **should** 文档化）。
- **should** 包含 `repeated string purge_sample` 字段：若 `force` 为 `false`，它 **should** 提供将被删除的 resource names 样本。若 `force` 为 true，此字段 **should not** 被填充。
  - 样本 **should** 足够大以捕捉明显错误：经验法则是 100。API **should** 文档化该大小，并且 **should** 文档化它是最大值（可能发送更少）。
  - 样本 **may** 随机或 **may** 确定性（例如最先匹配的 resource names）。API **should** 文档化使用哪种方法。
  - 该字段 **should** 标识它所引用的 [resource type]({{< ref "aip-0123" >}})。

**Note:** 即使不包含 `purge_count` 与 `purge_sample`，请求中 **must** 仍包含 `force` 字段。
