**英文标题**：Field masks  
**原文**：[AIP-161](https://google.aip.dev/161) · approved · 创建 2021-03-01  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

常常，在更新资源时（使用 [AIP-134]({{< ref "aip-0134" >}}) 中定义的 update 方法或某种合理类似的方法），希望精确指定正在更新哪些字段，以便服务忽略其余字段，即使用户发送了新值。

为每个 API 的精确需求定义 mask 格式很诱人。然而，masking 要求会演进，因此明智的做法是使用结构化语法。这允许透明地更新，而无需等待 UI 或客户端更新。

## Guidance

这些字段名的 masks 称为 "field masks"。表示 field mask 的字段 **must** 使用 `google.protobuf.FieldMask` 类型。Field masks 在 Update 请求上最常见（[AIP-134]({{< ref "aip-0134" >}})）。

Field masks **must** 始终相对于资源：

**Warning:** 作为请求 message 上单个字段的 Read masks，例如 `google.protobuf.FieldMask read_mask` **已废弃**。改为见 [AIP-157]({{< ref "aip-0157" >}})。

```proto
message UpdateBookRequest {
  // The book to update.
  //
  // The book's `name` field is used to identify the book to update.
  // Format: publishers/{publisher}/books/{book}
  Book book = 1 [(google.api.field_behavior) = REQUIRED];

  // The list of fields to update.
  // Fields are specified relative to the book
  // (e.g. `title`, `rating`; *not* `book.title` or `book.rating`).
  google.protobuf.FieldMask update_mask = 2;
}
```

### Read-write consistency

若存在 mask，field masks 的读写行为 **must** 自洽：

- 若用户用给定 mask 更新资源，然后用同一 mask 读取同一资源，**must** 返回完全相同的数据。
  - 例外：[Output only fields](#output-only-fields)。
- 类似地，用给定 mask 读取资源，然后用返回的数据与同一 mask 更新该资源 **must** 为 no-op。

**Note:** 这意味着对读或写有效的任何 mask **must** 对二者都有效。

### Specifying specific fields

Field masks **must** 允许指定已定义 struct 中的特定字段，使用 `.` 字符遍历。

因为 field masks 始终相对于资源，资源上的直接字段不需要遍历（例如：`title`、`rating`）。当资源包含 messages 时使用遍历（例如：`author.given_name`）。

**Note:** 用户 **must** 能够指定整个字段或其某个子字段：`author` 与 `author.given_name` 都有效。

### Map fields

当且仅当 map 的键为字符串或整数时，Field masks **may** 允许指定 map 中的特定字段，使用 `.` 字符遍历。

Field masks **should** 支持包含对 field mask 语法有问题的字符的字符串键，使用反引号字符。

```proto
message Book {
  // The name of the book.
  // Format: publishers/{publisher}/books/{book}
  string name = 1;

  // Reviews for the back cover. The key is the author of the review,
  // and the value is the text of the review.
  //
  // Valid field masks: reviews, reviews.smith, reviews.`John Smith`
  map<string, string> reviews = 2;
}
```

### Wildcards

Field masks **may** 允许在 repeated 字段或 map 上使用 `*` 字符，以表示指定集合中的特定子字段：

```proto
message Book {
  option (google.api.resource) = {
    type: "library.googleapis.com/Book"
    pattern: "publishers/{publisher}/books/{book}"
  };

  // The name of the book.
  // Format: publishers/{publisher}/books/{book}
  string name = 1 [(google.api.field_behavior) = IDENTIFIER];

  // The author or authors of the book.
  // Valid field masks: authors, authors.*.given_name, authors.*.family_name
  // Invalid field masks: authors.0, authors.0.given_name
  repeated Author authors = 2;
}

message Author {
  // The author's given name.
  string given_name = 1;

  // The author's family name.
  string family_name = 2;
}
```

**Note:** Field masks **must not** 允许按索引访问 repeated 字段的特定元素，并且若试图这样做 **must** 返回 `INVALID_ARGUMENT` 错误。

### Output only fields

若用户通过通配符或指定包含 output-only 子字段的整体 message 间接把 output only 字段包含在 update mask 中，服务 **must** 忽略作为输入提供的任何 output only 字段，即使它们被清除或修改。

若用户在 update mask 中直接指定 output only 字段，服务 **must** 忽略作为输入提供的 output only 字段，即使它们被清除或修改，以便同一 field mask 可用于输入与输出。

### Invalid field mask entries

读取数据时，Field masks **may** 忽略指向不能存在的值的条目（要么字段不存在，要么服务视为无效的 map 键）。

写入数据时，若条目指向不能存在的值，Field masks **should** 返回 `INVALID_ARGUMENT` 错误；然而，服务 **may** 允许删除。
