**英文标题**：Field masks  
**原文**：[AIP-161](https://google.aip.dev/161) · approved · 创建 2021-03-01

更新资源时（Update，见 [AIP-134]({{< ref "aip-0134" >}})；或差不多的方法），常常只想精确指定正在改哪些字段。其余字段服务应当忽略，即使用户顺手发了新值。

为每个 API 单独设计 mask 格式，很诱人。但 masking 需求会变。更稳妥的做法是用结构化语法，可以透明演进，不必等 UI 或客户端先改。

## 相对于资源

这些字段名的 masks 叫 field masks。表示 field mask 的字段必须用 `google.protobuf.FieldMask` 类型。Field masks 在 Update 请求上最常见（见 [AIP-134]({{< ref "aip-0134" >}})）。

Field masks 必须始终相对于资源。

**Warning:** 作为请求 message 上单个字段的 read masks，例如 `google.protobuf.FieldMask read_mask`，**已废弃**。改见 [AIP-157]({{< ref "aip-0157" >}})。

```proto
message UpdateBookRequest {
  // The book to update.
  //
  // The book's `name` field is used to identify the book to update.
  // Format: publishers/{publisher}/books/{book}
  Book book = 1 [(google.api.field_behavior) = REQUIRED];

  // The list of fields to update.
  // Fields are specified relative to the book
  // (e.g. `title`, `rating`; *not* `book.title` or `book.rating`).
  google.protobuf.FieldMask update_mask = 2;
}
```

## 读写一致

若存在 mask，field masks 的读写行为必须自洽：

- 用户用给定 mask 更新资源，再用同一 mask 读同一资源，必须返回完全相同的数据。
  - 例外：[output only 字段](#output-only-字段)。
- 反过来：用给定 mask 读资源，再用返回的数据与同一 mask 更新该资源，必须是 no-op。

这意味着：对读或写有效的任何 mask，必须对二者都有效。

## 指定特定字段

Field masks 必须允许指定已定义 struct 中的特定字段，用 `.` 遍历。

因为 field masks 始终相对于资源，资源上的直接字段不需要遍历（例如 `title`、`rating`）。资源里套了 messages 时才用遍历（例如 `author.given_name`）。

用户必须能指定整个字段，或它的某个子字段：`author` 与 `author.given_name` 都有效。

## Map 字段

当且仅当 map 的键为字符串或整数时，field masks 可以允许指定 map 中的特定字段，用 `.` 遍历。

Field masks 应当支持包含对 field mask 语法有问题的字符的字符串键，用反引号包起来。

```proto
message Book {
  // The name of the book.
  // Format: publishers/{publisher}/books/{book}
  string name = 1;

  // Reviews for the back cover. The key is the author of the review,
  // and the value is the text of the review.
  //
  // Valid field masks: reviews, reviews.smith, reviews.`John Smith`
  map<string, string> reviews = 2;
}
```

## 通配符

Field masks 可以允许在 repeated 字段或 map 上用 `*`，表示指定集合中的特定子字段：

```proto
message Book {
  option (google.api.resource) = {
    type: "library.googleapis.com/Book"
    pattern: "publishers/{publisher}/books/{book}"
  };

  // The name of the book.
  // Format: publishers/{publisher}/books/{book}
  string name = 1 [(google.api.field_behavior) = IDENTIFIER];

  // The author or authors of the book.
  // Valid field masks: authors, authors.*.given_name, authors.*.family_name
  // Invalid field masks: authors.0, authors.0.given_name
  repeated Author authors = 2;
}

message Author {
  // The author's given name.
  string given_name = 1;

  // The author's family name.
  string family_name = 2;
}
```

Field masks 不得允许按索引访问 repeated 字段的特定元素。若试图这样做，必须返回 `INVALID_ARGUMENT`。

## Output only 字段

若用户通过通配符、或指定包含 output-only 子字段的整体 message，间接把 output only 字段放进 update mask，服务必须忽略作为输入提供的任何 output only 字段，即使它们被清除或修改。

若用户在 update mask 里直接指定 output only 字段，服务必须忽略作为输入提供的 output only 字段，即使它们被清除或修改。这样同一 field mask 才能同时用于输入与输出。

## 无效的 field mask 条目

读数据时，field masks 可以忽略指向不能存在的值的条目（字段不存在，或服务视为无效的 map 键）。

写数据时，若条目指向不能存在的值，field masks 应当返回 `INVALID_ARGUMENT`；不过服务可以允许删除。
