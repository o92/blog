**英文标题**：Resource association

资源树通常是一对多往下挂。现实里常常不够用：一个资源可能跟两种其它类型都是多对一，或者跟另一种类型是多对多。这篇讲这种「画不进一棵干净树」的关联怎么建模。

## 规范 parent 只能有一个

资源至多只能有一个规范 parent。`List` 请求不得靠两个不同的 "parents" 才能跑起来。

### 多个多对一

跟多种资源类型都是多对一关系时，必须从中选出至多一个当规范 parent。跟其它资源的关联，可以放在资源上的其它字段里。

```proto
message Book {
  // The resource name pattern for Book indicates that Publisher is the
  // canonical parent.
  option (google.api.resource) = {
    type: "library.googleapis.com/Book"
    pattern: "publishers/{publisher}/books/{book}"
  };

  // The resource name for the book.
  string name = 1 [(google.api.field_behavior) = IDENTIFIER];

  // The resource name for the book's author.
  string author = 2 [(google.api.resource_reference) = {
    type: "library.googleapis.com/Author"
  }];
}
```

列出这种带多个关联的资源时，RPC 必须把 `string parent` 当成必填，规则见 [AIP-132]({{< ref "aip-0132" >}})。不得再加别的必填参数。应当带一个 `string filter`，让用户按其它资源关联过滤，规则见 [AIP-160]({{< ref "aip-0160" >}})。

Resource reference 字段必须接受与被引用资源 `name` 字段相同的 resource name 格式。

### 多对多

多对多在 API 里比在关系数据库里少见。一部分原因是更难建模，也更难通过网络接口呈现。

API 可以包含多对多关系。应当用含 resource names 列表的 repeated 字段，并遵循 [AIP-144]({{< ref "aip-0144" >}}) 对 repeated fields 的原则。

```proto
message Book {
  option (google.api.resource) = {
    type: "library.googleapis.com/Book"
    pattern: "publishers/{publisher}/books/{book}"
  };

  string name = 1 [(google.api.field_behavior) = IDENTIFIER];

  // The resource names for the book's authors.
  repeated string authors = 2 [(google.api.resource_reference) = {
    type: "library.googleapis.com/Author"
  }];
}
```

repeated fields 的更多细节，包括原子变更怎么处理，见 [AIP-144]({{< ref "aip-0144" >}})。

若 repeated 字段太受限，或关联上还需要更多元数据，可以用子资源来建模：子资源带两个一对多关联，合起来就是多对多。

```proto
message BookAuthor {
  // The resource pattern for BookAuthor indicates that Book is the
  // canonical parent.
  option (google.api.resource) = {
    type: "library.googleapis.com/BookAuthor"
    pattern: "publishers/{publisher}/books/{book}/authors/{book_author}"
  };

  // The resource name for the book-author association.
  string name = 1 [(google.api.field_behavior) = IDENTIFIER];

  // The resource name for the author.
  string author = 2 [(google.api.resource_reference) = {
    type: "library.googleapis.com/Author"
  }];

  // Other fields...
}
```

只有关系上还需要额外元数据，或 repeated 字段的限制已经排除那种做法时，才建议用子资源来建模关联。
