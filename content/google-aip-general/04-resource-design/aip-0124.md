**英文标题**：Resource association  
**原文**：[AIP-124](https://google.aip.dev/124) · approved · 创建 2020-03-20  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

APIs 有时具有无法干净表达为通常树结构的资源层级。例如，某资源可能与两种其它资源类型都有多对一关系，而不是只与一种。或者，某资源可能与另一资源类型有多对多关系。

## Guidance

资源 **must** 至多有一个规范 parent，并且 `List` 请求 **must not** 要求两个不同的 "parents" 才能工作。

### 多个多对一关联

若某资源与多种资源类型有多对一关系，它 **must** 选择其中至多一个作为规范 parent。该资源 **may** 通过资源上的其它字段与其它资源关联。

```proto
message Book {
  // The resource name pattern for Book indicates that Publisher is the
  // canonical parent.
  option (google.api.resource) = {
    type: "library.googleapis.com/Book"
    pattern: "publishers/{publisher}/books/{book}"
  };

  // The resource name for the book.
  string name = 1 [(google.api.field_behavior) = IDENTIFIER];

  // The resource name for the book's author.
  string author = 2 [(google.api.resource_reference) = {
    type: "library.googleapis.com/Author"
  }];
}
```

以此方式列出带多个关联的资源时，RPC **must** 把 `string parent` 字段视为必填，如 [AIP-132]({{< ref "aip-0132" >}}) 所述，并且 **must not** 增加额外的必填参数。RPC **should** 包含 `string filter` 字段，允许用户按其它资源关联过滤，如 [AIP-160]({{< ref "aip-0160" >}}) 所述。

**Note:** Resource reference 字段 **must** 接受与被引用资源 `name` 字段所用相同的 resource name 格式。

### 多对多关联

多对多关联在 APIs 中比在关系数据库中少见，部分是因为它们更难建模，也更难通过网络接口呈现。

API **may** 包含多对多关系，并且 **should** 使用含 resource names 列表的 repeated 字段，遵循 [AIP-144]({{< ref "aip-0144" >}}) 中关于 repeated fields 的原则。

```proto
message Book {
  option (google.api.resource) = {
    type: "library.googleapis.com/Book"
    pattern: "publishers/{publisher}/books/{book}"
  };

  string name = 1 [(google.api.field_behavior) = IDENTIFIER];

  // The resource names for the book's authors.
  repeated string authors = 2 [(google.api.resource_reference) = {
    type: "library.googleapis.com/Author"
  }];
}
```

**Note:** 关于 repeated fields 的更多信息，包括如何处理原子变更等常见问题，见 [AIP-144]({{< ref "aip-0144" >}})。

若使用 repeated 字段过于受限，或关联上还需要更多元数据，API **may** 用带子资源、带两个一对多关联的方式来建模多对多关系。

```proto
message BookAuthor {
  // The resource pattern for BookAuthor indicates that Book is the
  // canonical parent.
  option (google.api.resource) = {
    type: "library.googleapis.com/BookAuthor"
    pattern: "publishers/{publisher}/books/{book}/authors/{book_author}"
  };

  // The resource name for the book-author association.
  string name = 1 [(google.api.field_behavior) = IDENTIFIER];

  // The resource name for the author.
  string author = 2 [(google.api.resource_reference) = {
    type: "library.googleapis.com/Author"
  }];

  // Other fields...
}
```

**Note:** 仅当关系中需要额外元数据，或 repeated 字段的限制排除了那种做法时，才建议用子资源来建模资源之间的关联。
