**英文标题**：Batch methods: Get  
**原文**：[AIP-231](https://google.aip.dev/231) · approved · 创建 2019-06-18 · 更新 2022-06-02  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

有些 APIs 需要允许用户在一致的时间点获取一组特定资源（例如使用读事务）。batch get 方法提供此功能。

## Guidance

APIs **may** 使用下列模式支持 Batch Get：

```proto
rpc BatchGetBooks(BatchGetBooksRequest) returns (BatchGetBooksResponse) {
  option (google.api.http) = {
    get: "/v1/{parent=publishers/*}/books:batchGet"
  };
}
```

- RPC 的名称 **must** 以 `BatchGet` 开头。RPC 名称的其余部分 **should** 为正在检索的资源的复数形式。
- 请求与响应 messages **must** 与 RPC 名称匹配，并带 `Request` 与 `Response` 后缀。
- HTTP 动词 **must** 为 `GET`。
- HTTP URI **must** 以 `:batchGet` 结尾。
- URI 路径 **should** 表示该资源的集合，与简单 CRUD 操作使用的集合匹配。若操作跨越 parents，**may** 接受短横线（`-`）作为通配符。
- `google.api.http` annotation 中 **must not** 有 body 键。
- 该操作 **must** 是原子的：它 **must** 对所有资源失败或对所有资源成功（没有部分成功）。需要部分失败的情形 **should** 使用 `List`（[AIP-132]({{< ref "aip-0132" >}})）methods。
  - 若操作覆盖多个 locations 且至少一个 location 宕机，该操作 **must** 失败。

### Request message

batch get 方法的请求 **should** 使用下列模式指定：

```proto
message BatchGetBooksRequest {
  // The parent resource shared by all books being retrieved.
  // Format: publishers/{publisher}
  // If this is set, the parent of all of the books specified in `names`
  // must match this field.
  string parent = 1 [
    (google.api.resource_reference) = {
      child_type: "library.googleapis.com/Book"
    }];

  // The names of the books to retrieve.
  // A maximum of 1000 books can be retrieved in a batch.
  // Format: publishers/{publisher}/books/{book}
  repeated string names = 2 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      type: "library.googleapis.com/Book"
    }];
}
```

- **should** 包含 `parent` 字段，除非正在检索的资源是顶层资源，以便纳入 URI 并允许单次权限检查。若调用方设置此字段，且任何正在检索的资源 name 中的 parent collection 不匹配，请求 **must** 失败。
  - 若每个请求只允许 1 个 parent，该字段 **should** 为必填。
  - 该字段 **should** 标识它所引用的 [resource type]({{< ref "aip-0122" >}})。
  - 该字段的注释 **should** 文档化资源 pattern。
- 请求 message **must** 包含一个 repeated 字段，接受指定要检索资源的 resource names。该字段 **should** 名为 `names`。
  - 若未提供任何 resource names，API **should** 以 `INVALID_ARGUMENT` 报错。
  - 该字段 **should** 为必填。
  - 该字段 **should** 标识它所引用的 [resource type]({{< ref "aip-0122" >}})。
  - 该字段的注释 **should** 文档化资源 pattern。
- 除 `name` 外的其它字段 **may** 从 [标准 Get 请求]({{< ref "aip-0131" >}})「提升」。没有办法让这些字段对不同资源接受不同值；若需要此能力，使用 [替代请求 message 形式](#nested-request-objects)。
- Batch get **should not** 支持分页，因为跨 API 调用的事务性极难实现或强制，并且请求已经定义了响应的确切范围。
- 请求 message **must not** 包含任何其它必填字段，并且 **should not** 包含其它可选字段，除非本文或另一篇 AIP 有描述。
- `names` 字段上方的注释 **should** 文档化允许的最大请求数。

### Response message

batch get 方法的响应 **should** 使用下列模式指定：

```proto
message BatchGetBooksResponse {
  // Books requested.
  repeated Book books = 1;
}
```

- 响应 message **must** 包含一个对应正在检索的资源的 repeated 字段。
- 响应中 books 的顺序 **must** 与请求中的 names 相同。

### Nested request objects

若 [标准 Get 请求 message]({{< ref "aip-0131" >}}) 包含除 resource name 外、在不同被请求资源之间需要不同的字段，batch message **may** 改为持有 [标准 Get 请求 message]({{< ref "aip-0131" >}}) 的 `repeated` 字段。除非用例确实需要，一般不鼓励这样做。

使用此方法的 batch get 请求 **should** 使用下列模式指定：

```proto
message BatchGetBooksRequest {
  // The parent resource shared by all books being retrieved.
  // Format: publishers/{publisher}
  // If this is set, the parent field in the GetBookRequest messages
  // must either be empty or match this field.
  string parent = 1 [
    (google.api.resource_reference) = {
      child_type: "library.googleapis.com/Book"
    }];

  // The requests specifying the books to retrieve.
  // A maximum of 1000 books can be retrieved in a batch.
  repeated GetBookRequest requests = 2
    [(google.api.field_behavior) = REQUIRED];
}
```

- **should** 包含 `parent` 字段。若调用方设置此字段，且任何正在检索的资源 name 中的 parent collection 不匹配，请求 **must** 失败。
  - 若每个请求只允许 1 个 parent，该字段 **should** 为必填。
  - 该字段 **should** 标识它所引用的 [resource type]({{< ref "aip-0122" >}})。
  - 该字段的注释 **should** 文档化资源 pattern。
- 请求 message **must** 包含一个 repeated 字段，接受指定要检索资源的请求 messages，如 [标准 Get methods]({{< ref "aip-0131" >}}) 所指定。该字段 **should** 名为 `requests`。
  - 该字段 **should** 为必填。
- 其它字段 **may** 从 [标准 Get 请求]({{< ref "aip-0131" >}})「提升」，意味着该字段可以在 batch 级或 child 请求级设置。与 `parent` 类似，若同一字段在 batch 级与 child 请求级都设置，值 **must** 匹配。
- Batch get **should not** 支持分页，因为跨 API 调用的事务性极难实现或强制，并且请求已经定义了响应的确切范围。
- 请求 message **must not** 包含任何其它必填字段，并且 **should not** 包含其它可选字段，除非本文或另一篇 AIP 有描述。
- `requests` 字段上方的注释 **should** 文档化允许的最大请求数。
