**英文标题**：Batch methods: Get  
**原文**：[AIP-231](https://google.aip.dev/231) · approved · 创建 2019-06-18 · 更新 2022-06-02  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

有时用户要在一致的时间点拿到一组指定资源（例如走读事务）。一条一条 Get 对不上同一快照。Batch Get 就是为这件事准备的。

## 怎么写

API 可以用下列模式支持 Batch Get：

```proto
rpc BatchGetBooks(BatchGetBooksRequest) returns (BatchGetBooksResponse) {
  option (google.api.http) = {
    get: "/v1/{parent=publishers/*}/books:batchGet"
  };
}
```

- RPC 名称必须以 `BatchGet` 开头。其余部分应当是正在检索的资源的复数。
- 请求与响应 messages 必须与 RPC 名称匹配，并带 `Request` 与 `Response` 后缀。
- HTTP 动词必须是 `GET`。
- HTTP URI 必须以 `:batchGet` 结尾。
- URI 路径应当表示该资源的集合，与简单 CRUD 用的集合一致。操作跨越 parents 时，可以接受短横线（`-`）当通配符。
- `google.api.http` annotation 中不得有 body 键。
- 该操作必须是原子的：必须对所有资源失败或对所有资源成功（没有部分成功）。需要部分失败时，应当改用 `List`（见 [AIP-132]({{< ref "aip-0132" >}})）。
  - 若操作覆盖多个 locations 且至少一个 location 宕机，该操作必须失败。

### 请求 message

应当用下列模式：

```proto
message BatchGetBooksRequest {
  // The parent resource shared by all books being retrieved.
  // Format: publishers/{publisher}
  // If this is set, the parent of all of the books specified in `names`
  // must match this field.
  string parent = 1 [
    (google.api.resource_reference) = {
      child_type: "library.googleapis.com/Book"
    }];

  // The names of the books to retrieve.
  // A maximum of 1000 books can be retrieved in a batch.
  // Format: publishers/{publisher}/books/{book}
  repeated string names = 2 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      type: "library.googleapis.com/Book"
    }];
}
```

- 应当包含 `parent` 字段，除非正在检索的资源是顶层资源。这样能放进 URI，也方便做单次权限检查。调用方设了此字段、且任何正在检索的资源 name 里的 parent collection 对不上时，请求必须失败。
  - 每个请求只允许 1 个 parent 时，该字段应当必填。
  - 该字段应当标明它所引用的 resource type（见 [AIP-122]({{< ref "aip-0122" >}})）。
  - 该字段的注释应当写清资源 pattern。
- 请求必须包含一个 repeated 字段，接受要检索资源的 resource names。该字段应当叫 `names`。
  - 若一个 resource name 都没给，API 应当以 `INVALID_ARGUMENT` 报错。
  - 该字段应当必填。
  - 该字段应当标明它所引用的 resource type（见 [AIP-122]({{< ref "aip-0122" >}})）。
  - 该字段的注释应当写清资源 pattern。
- 除 `name` 外的其它字段可以从标准 Get 请求（见 [AIP-131]({{< ref "aip-0131" >}})）「提升」。这些字段没法对不同资源接受不同值；若需要，用下文的嵌套请求形式。
- Batch get 不应当支持分页：跨 API 调用的事务性极难实现或强制，而且请求已经把响应范围划死了。
- 请求不得包含任何其它必填字段，也不应当包含其它可选字段，除非本文或另一篇 AIP 有描述。
- `names` 上方的注释应当写清允许的最大请求数。

### 响应 message

应当用下列模式：

```proto
message BatchGetBooksResponse {
  // Books requested.
  repeated Book books = 1;
}
```

- 响应必须包含一个对应正在检索的资源的 repeated 字段。
- 响应里 books 的顺序必须与请求里的 names 相同。

### 嵌套请求对象

若标准 Get 请求（见 [AIP-131]({{< ref "aip-0131" >}})）除 resource name 外还有字段，且这些字段在不同被请求资源之间需要不同值，batch message 可以改为持有标准 Get 请求的 `repeated` 字段。除非用例确实需要，一般不鼓励这样做。

用这种方式时，请求应当是：

```proto
message BatchGetBooksRequest {
  // The parent resource shared by all books being retrieved.
  // Format: publishers/{publisher}
  // If this is set, the parent field in the GetBookRequest messages
  // must either be empty or match this field.
  string parent = 1 [
    (google.api.resource_reference) = {
      child_type: "library.googleapis.com/Book"
    }];

  // The requests specifying the books to retrieve.
  // A maximum of 1000 books can be retrieved in a batch.
  repeated GetBookRequest requests = 2
    [(google.api.field_behavior) = REQUIRED];
}
```

- 应当包含 `parent`。调用方设了此字段、且任何正在检索的资源 name 里的 parent collection 对不上时，请求必须失败。
  - 每个请求只允许 1 个 parent 时，该字段应当必填。
  - 该字段应当标明它所引用的 resource type（见 [AIP-122]({{< ref "aip-0122" >}})）。
  - 该字段的注释应当写清资源 pattern。
- 请求必须包含一个 repeated 字段，接受标准 Get 请求 messages。该字段应当叫 `requests`。
  - 该字段应当必填。
- 其它字段可以从标准 Get 请求「提升」，意思是该字段可以在 batch 级或 child 请求级设置。跟 `parent` 一样，同一字段在两级都设了时，值必须匹配。
- Batch get 不应当支持分页：跨 API 调用的事务性极难实现或强制，而且请求已经把响应范围划死了。
- 请求不得包含任何其它必填字段，也不应当包含其它可选字段，除非本文或另一篇 AIP 有描述。
- `requests` 上方的注释应当写清允许的最大请求数。

- **2022-06-02**：更改后缀描述，去掉多余的 "-"。
- **2020-09-16**：建议为 `parent`、`names` 与 `requests` 字段加 annotations。

- **2020-03-24**：澄清未发送任何 resource names 时的行为。

- **2019-08-01**：把示例从 "shelves" 改为 "publishers"，以更好展示资源所有权。
