**英文标题**：Standard methods: Get  
**原文**：[AIP-131](https://google.aip.dev/131) · approved · 创建 2019-01-22 · 更新 2022-06-02  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

用户要核对某个资源现在长什么样，就得有一条只读这一条资源的路。Get 就是这条路：给 resource name，拿回这个资源。REST 里对应的是对资源 URI（例如 `/v1/publishers/{publisher}/books/{book}`）发 `GET`。面向资源的设计（见 [AIP-121]({{< ref "aip-0121" >}})）把这套语义收成 `Get` 方法。

## 怎么写

API 必须为资源提供 get 方法。目的只有一个：返回单个资源的数据。

模式如下：

```proto
rpc GetBook(GetBookRequest) returns (Book) {
  option (google.api.http) = {
    get: "/v1/{name=publishers/*/books/*}"
  };
  option (google.api.method_signature) = "name";
}
```

- RPC 名称必须以 `Get` 开头。其余部分应当是该资源 message 名称的单数。
- 请求 message 必须与 RPC 名称匹配，并带 `Request` 后缀。
- 响应 message 必须是资源本身。没有 `GetBookResponse`。
  - 除非有理由返回部分响应（见 [AIP-157]({{< ref "aip-0157" >}})），响应应当通常包含完全填充的资源。
- HTTP 动词必须是 `GET`。
- URI 应当只含一个对应资源名称的变量字段。
  - 该字段应当叫 `name`。
  - URI 应当有对应该字段的变量。
  - `name` 应当是 URI 路径里唯一的变量。其余参数应当映射到 URI query parameters。
- `google.api.http` annotation 中不得有 `body` 键。
- 应当恰好有一个 `google.api.method_signature` annotation，值为 `"name"`。

### 请求 message

Get 用一套常见的请求形状：

```proto
message GetBookRequest {
  // The name of the book to retrieve.
  // Format: publishers/{publisher}/books/{book}
  string name = 1 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      type: "library.googleapis.com/Book"
    }];
}
```

- 必须包含 resource name 字段。应当叫 `name`。
  - 该字段应当标为 required（见 [AIP-203]({{< ref "aip-0203" >}})）。
  - 该字段必须标明它所引用的 resource type（见 [AIP-123]({{< ref "aip-0123" >}})）。
- `name` 字段的注释应当写清资源 pattern。
- 请求 message 不得包含任何其它必填字段，也不应当包含其它可选字段，除非另一篇 AIP 有描述。

请求对象里的 `name` 对应 RPC 上 `google.api.http` annotation 里的 `name` 变量。走 REST/JSON 时，这个字段会按 URL 里的值填上。

### 错误

见 [AIP-193]({{< ref "aip-0193" >}})，尤其是何时用 PERMISSION_DENIED 与 NOT_FOUND。
