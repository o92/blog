**英文标题**：Standard methods: Get  
**原文**：[AIP-131](https://google.aip.dev/131) · approved · 创建 2019-01-22 · 更新 2022-06-02  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

在 REST APIs 中，习惯对资源的 URI（例如 `/v1/publishers/{publisher}/books/{book}`）发出 `GET` 请求以检索该资源。

面向资源的设计（[AIP-121]({{< ref "aip-0121" >}})）通过 `Get` 方法尊重此模式。这些 RPCs 接受表示该资源的 URI，并返回该资源。

## Guidance

APIs **must** 为资源提供 get 方法。get 方法的目的是返回单个资源的数据。

Get methods 使用下列模式指定：

```proto
rpc GetBook(GetBookRequest) returns (Book) {
  option (google.api.http) = {
    get: "/v1/{name=publishers/*/books/*}"
  };
  option (google.api.method_signature) = "name";
}
```

- RPC 的名称 **must** 以单词 `Get` 开头。RPC 名称的其余部分 **should** 为该资源 message 名称的单数形式。
- 请求 message **must** 与 RPC 名称匹配，并带 `Request` 后缀。
- 响应 message **must** 为资源本身。（没有 `GetBookResponse`。）
  - 除非有理由返回部分响应（见 [AIP-157]({{< ref "aip-0157" >}})），响应 **should** 通常包含完全填充的资源。
- HTTP 动词 **must** 为 `GET`。
- URI **should** 包含对应资源名称的单个变量字段。
  - 该字段 **should** 称为 `name`。
  - URI **should** 有对应该字段的变量。
  - `name` 字段 **should** 是 URI 路径中的唯一变量。其余参数 **should** 映射到 URI query parameters。
- `google.api.http` annotation 中 **must not** 有 `body` 键。
- **should** 恰好有一个 `google.api.method_signature` annotation，值为 `"name"`。

### Request message

Get methods 实现一种常见的请求 message 模式：

```proto
message GetBookRequest {
  // The name of the book to retrieve.
  // Format: publishers/{publisher}/books/{book}
  string name = 1 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      type: "library.googleapis.com/Book"
    }];
}
```

- **must** 包含 resource name 字段。它 **should** 称为 `name`。
  - 该字段 **should** 被标注为 required（[AIP-203]({{< ref "aip-0203" >}})）。
  - 该字段 **must** 标识它所引用的 resource type（[AIP-123]({{< ref "aip-0123" >}})）。
- `name` 字段的注释 **should** 文档化资源 pattern。
- 请求 message **must not** 包含任何其它必填字段，并且 **should not** 包含其它可选字段，除非另一篇 AIP 有描述。

**Note:** 请求对象中的 `name` 字段对应 RPC 上 `google.api.http` annotation 中的 `name` 变量。这导致在使用 REST/JSON 接口时，请求中的 `name` 字段根据 URL 中的值填充。

### Errors

见 errors（[AIP-193]({{< ref "aip-0193" >}})），尤其是何时使用 PERMISSION_DENIED 与 NOT_FOUND 错误（[AIP-193]({{< ref "aip-0193" >}})）。
