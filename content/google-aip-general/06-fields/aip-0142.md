**英文标题**：Time and duration  
**原文**：[AIP-142](https://google.aip.dev/142) · approved · 创建 2019-07-16  
**许可**：原文 © Google，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

许多服务需要表示围绕时间的概念。由于日历与时区的错综复杂，以及常见交换格式（例如 JSON）缺少原生时间概念，表示时间可能具有挑战。

## Guidance

表示时间的字段 **should** 使用常见、普遍使用的组件（例如 [`google.protobuf.Timestamp`](https://github.com/protocolbuffers/protobuf/blob/master/src/google/protobuf/timestamp.proto) 或 [`google.type.Date`](https://github.com/googleapis/googleapis/blob/master/google/type/date.proto)）来表示时间或时长类型。这些类型是 [common components]({{< ref "aip-0213" >}})，一致使用它们能让基础设施与工具在与时间值交互时提供更好的体验。

### Timestamps

表示绝对时间点（独立于任何时区或日历）的字段 **should** 使用 [`google.protobuf.Timestamp`](https://github.com/protocolbuffers/protobuf/blob/master/src/google/protobuf/timestamp.proto) 类型（底层使用 UNIX timestamps，并保持纳秒精度）。

这些字段 **should** 有以 `_time` 结尾的名称，例如 `create_time` 或 `update_time`。对 repeated 字段，名称 **should** 改为以 `_times` 结尾。

许多时间戳字段指一项活动（例如，`create_time` 指适用资源何时被创建）。对这些，字段 **should** 以 `{imperative}_time` 形式命名。例如，若一本书正在出版，存储此事发生时间的字段会使用动词 "to publish" 的祈使形式（"publish"），得到名为 `publish_time` 的字段。字段 **should not** 用过去时命名（例如 `published_time`、`created_time` 或 `last_updated_time`）。

### Durations

表示两个时间点之间的跨度（独立于任何时区或日历）的字段 **should** 使用 [`google.protobuf.Duration`](https://github.com/protocolbuffers/protobuf/blob/master/src/google/protobuf/duration.proto) 类型。

为说明时间戳与时长的区别，考虑一条航班记录：

```proto
// A representation of a (very incomplete) flight log.
message FlightRecord {
  // The absolute point in time when the plane took off.
  google.protobuf.Timestamp takeoff_time = 1;

  // The length (duration) of the flight, from takeoff to landing.
  google.protobuf.Duration flight_duration = 2;
}
```

**Note:** 细心的读者可能注意到 [timestamp](https://github.com/protocolbuffers/protobuf/blob/master/src/google/protobuf/timestamp.proto) 与 [duration](https://github.com/protocolbuffers/protobuf/blob/master/src/google/protobuf/duration.proto) messages 有相同结构（`int64 seconds` 与 `int32 nanos`）。然而，二者的区分很重要，因为它们有不同的语义含义。此外，工具能够根据使用哪个 message 来决定行为。例如，基于 Python 的工具可以把 timestamps 转换为 [datetime](https://docs.python.org/3/library/datetime.html#datetime.datetime) 对象，把 durations 转换为 [timedelta](https://docs.python.org/3/library/datetime.html#datetime.timedelta) 对象。

### Relative time segments

有时可能需要表示流内部的时间片段。此时 **should** 使用 [`google.protobuf.Duration`](https://github.com/protocolbuffers/protobuf/blob/master/src/google/protobuf/duration.proto) 类型，并且字段名 **should** 以 `_offset` 结尾。为确保含义清楚，该字段 **must** 有注释说明该偏移相对于哪一点。

为说明这一点，考虑表示音频流片段的资源：

```proto
message AudioSegment {
  // The duration relative to the start of the stream representing the
  // beginning of the segment.
  google.protobuf.Duration start_offset = 1;

  // The total length of the segment.
  google.protobuf.Duration segment_duration = 2;
}
```

### Civil dates and times

表示日历日期或墙上时钟时间的字段 **should** 使用适当的 common components：

- 民用日期：[`google.type.Date`](https://github.com/googleapis/googleapis/blob/master/google/type/date.proto)
- 墙上时钟时间：[`google.type.TimeOfDay`](https://github.com/googleapis/googleapis/blob/master/google/type/timeofday.proto)

表示民用日期的字段 **should** 有以 `_date` 结尾的名称，而表示民用时间或日期时间的字段 **should** 有以 `_time` 结尾的名称。

**Note:** `Date` 与 `TimeOfDay` 组件都是时区无关的。需要时区感知的字段 **should** 使用 `DateTime`（见下文）。

### Civil timestamps

表示民用时间戳（日期与时间，可选带时区）的字段 **should** 使用 [`google.type.DateTime`](https://github.com/googleapis/googleapis/blob/master/google/type/datetime.proto) 组件，并且字段名 **should** 以 `_time` 结尾。

### Compatibility

偶尔，APIs 因遗留或兼容性原因无法使用常见结构。例如，API 可能符合另一份规范，该规范强制时间戳为整数或 [ISO-8601](https://www.iso.org/iso-8601-date-and-time-format.html) 字符串。

此时，字段 **may** 使用其它类型。若可能，适用下列命名约定：

- 对整数，包含含义（例如：`time`、`duration`、`delay`、`latency`）**以及**计量单位（有效值：`seconds`、`millis`、`micros`、`nanos`）作为最终后缀。例如，`send_time_millis`。
- 对字符串，包含含义（例如：`time`、`duration`、`delay`、`latency`）但不带单位后缀。

在所有情形下，清楚文档化期望格式，以及使用它的理由。
