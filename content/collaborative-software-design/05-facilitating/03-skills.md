对应原书 **5.3**：Clear communication、Active listening、Holding space——建立在三大能力之上，也可反哺能力。

## Clear communication（5.3.1）

童年蒙眼指路游戏：说「往前五步」却只剩三步就撞墙——沟通不是「我说了你就懂」的单向管道。长大后领域词多义、同词异义会直接进决策。清晰沟通 = 尽量少歧义地传达意图；它是动态、非线性交换，不是教科书里的直线箭头。

三块落地：

1. **Planning** — 目标清楚 → 话才说得准；议程与预习让「需要时间消化」的人也能带智慧进场，否则会沉默。  
2. **Shared language architecture** — 不强迫大家用你的词；帮群体发现并设计自己的语言与隐喻。例：保险场景 EventStorm 的「policy」便签会撞业务「保单」——换词。BigScreen：主题日买的是「入场」不是「座位」→ 事件改称 Ticket Sold，座位变可选。两件事：当翻译（跨学科大声同意 / 沉默不同意时用苏格拉底追问澄清）+ 设计 ubiquitous language（清理「customer / client / product」等同词异义）。  
3. **Summarizing** — 实时蒸馏决策与理解，当罗盘；收场总结既照镜子（做了什么）也开窗（下一步挖哪、立刻动哪）。

苏格拉底式追问可改编进会话（澄清、探假设、探理由/证据、视角、后果、元问题）；最实用的一句是要**例子**。

## Active Listening（5.3.2）

源自临床心理：全神贯注于对方，而不是准备反驳或塞方案。

- 开放式问题：「能多说一点吗？」  
- 复述确认：「我理解你是说……」  
- 情绪重时尤其：**先听完**，再谈解决  

与观察互补：听内容，也听未说出的部分。中立 + 倾听 → 更多信息进场。

## Holding Space（5.3.3）

为人留出被听见、被感受的空间（Heather Plett 等有专书）。

- 不急着打断、纠正、用自己故事盖过去  
- 愿景冲突时：**两种都建模并命名**，并置比较，而非立刻掐死其一  
- 沉默也可以是空间的一部分——练习忍住「必须填满空气」  

三技能相互加强：听清 → 问清 → 托住；中立与慈悲决定你能否用好它们。这只是起步清单，引导技能会持续演化。
