## Catalysts（7.4）

1. **记下行为模式并挂钩偏差**  
   在会议或协作建模中写下人们的行为模式，试着对应本章偏差；它对过程、结果、群体动力学各有何影响？若舒适，会中或会后与群体分享观察。

2. **先个人贡献，再群体讨论**  
   下次有知识分享的会：在集体讨论前留出个人贡献时间，减轻 **anchoring**。例如每人先把想法写在便利贴上，再分享。

3. **带头可视化**  
   当讨论只在口头打转、无人画流程时，你先动手可视化；观察效果。

4. **准备下场 nudge**  
   为下次会话准备助推：预设计的模板、你先画选项/对话、特定用词与概念等。写清：这个 nudge 是什么、想达成什么。

## 可抄进 journal 的 Guiding 启发式（7.5，摘要）

- 复杂/繁杂场景做 Example Mapping：可预做模板，少把时间耗在「怎么画例子」上  
- 对话未被可视化时，引导者先动手画  
- 复杂场景也可**少给结构**，降低 functional fixedness  
- Model it wrong：故意建「不想要」的领域模型，逼出洞见、绕开功能固着  
- 确认偏差：问什么证据能改变对方想法  
- 某词被滥用：换词，或限制使用该词再建模，看领域模型是否变化  
- 偏向往决策环境里**加** nudge（改环境）  
- 想让人拥有会话：示范一次，然后退后  
- 预期大量闲置：可先与两人预跑，由他们 nudge 其余人跟上  
- 想让人多做协作建模：开会时工具随手可得，降低起步门槛
