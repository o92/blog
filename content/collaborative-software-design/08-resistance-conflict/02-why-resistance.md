对应原书 **8.1**：冲突不等于吼叫摔门；阻力也不等于《星球大战》式英雄叙事——两者在协作里更常是日常、可预期的动力学。

## 冲突是什么（8.1.1）

口语里的「冲突」常联想到怒吼摔门——那是极端形态；多数冲突在表面下焖了很久才爆。

书中基线：**Conflict = 两人或多人之间的意见差异**。日常争论、谈妥、继续——我们甚至不称之为冲突。冲突是自然的。

| 类型 | 焦点 | 作用 |
|--|--|--|
| **Functional / task-based** | 内容与任务 | 可推动进展、创新与成长——**不要一味回避** |
| **Dysfunctional / relationship** | 情绪与个人 | 阻碍进展、强化权力动力学（如恶化 ranking）、伤害关系与心理安全 |

> GUIDING：先判断偏任务还是偏情绪、是助推还是妨碍进展。对话滑向「谁对谁错」时，常是功能失调的信号，引导者该介入化解。

忽视、未理解就驳回意见 → 人感到不被重视又难明说 → 冲突退入阴影。可持续决策需要挖不同视角。

**The odd one out（「Harry」）**：公司里总有「想法总听起来疯」的人，玩笑开到当面，新人被告知别当真。这本身就是未觉察的冲突；Harry 的「疯主意」有时正是触发新洞见的入口——别急着否，自己偶尔也当一回 Harry。

### 功能失调冲突的常见阶段

可跳级、可叠级；用来观察「煮到哪了」，而非刻板套路径：

| 阶段 | 信号 |
|--|--|
| Tension and taboo | 一提某题就紧，甚至成禁忌 |
| Double messages | 嘴上「我 OK」随即关摄像头 / 上厕所（词与音乐不一致） |
| Arguing with yourself | 对方不在场也在脑中反复吵架 |
| Gossip | 找人站队、确认自己正确（确认偏差） |
| Communication breaks down | 不再直说，托人「你去告诉他他错了」 |
| What was the problem again? | 原冲突忘了，一切关于对方都错 |
| -isms | 用刻板印象看对方（「象牙塔架构师」） |
| War or separation | 协作停、精疲力竭、离职/调部门；讽刺的是：到这步反而又能公开谈了 |

冲突**可见**时还有救；被压住才糟——回避 → Edge Behavior；久拖未决 → Resistance。

## Edge Behavior（8.1.2）

冲突令人不适 → **conflict avoidance** → **Edge Behavior**：乍看不合理、与意识层叙事矛盾的行为（卡住意识与无意识的边）。当事人想避冲突，又还没准备好正面谈。**勿急于评判**——待在不适里很难（猫临战突然舔毛也是边缘行为）。

边上常见的混乱沟通：

- **Absence**：人在心不在，点头微笑却已 check out  
- **Interruption**：打断增多；看是「一人专断一人」还是全场混战  
- **Indirect / 假问题 / 谬误论证**：把假设说成共识（「大家都同意这些边界吧？」）  

## Resistance（8.1.3）

觉得没被听见、意见未进决策时，人以阻力表达冲突。例：一提到某话题就看窗外；远端关摄像头——一类沟通断裂。

**Resistance line**（Lewis Deep Democracy；早期称 terrorist line）：从较轻（讽刺玩笑、借口等）到较重阶段；少数派或个人都可能沿线上移，群体效能随之下降。阻力是**正常**行为——人人都会。引导者要找**连贯模式**（对本场或公司更大张力），而不是把每一句玩笑都当事故。

未处理的冲突与阻力会与 ranking、认知偏差缠在一起，一起塑造软件设计结果。
