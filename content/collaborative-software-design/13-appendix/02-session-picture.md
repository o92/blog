对应原书 **Appendix A**：用一张全景图收束全书心智模型（此处只摘要图意，不转载原图）。

## 图里有什么

想象一场协作建模：

| 层 | 内容 |
|--|--|
| **建模空间** | 参与者用多种工具一起做软件模型 |
| **引导者** | 推进过程，朝「可持续设计决策」与本场目标走 |
| **桌上的工具箱** | 建模工具、风格、ingredients、heuristics——可混搭 |
| **对话气泡 + 阴影** | 社会动力学；阴影 = ranking / 偏差 / 冲突 / 极性等无意识部分 |
| **手电筒** | 引导者把阴影照可见、可管理 |
| **Demons** | 阴影不管会变大，挡共享理解与目标 |

## 怎么读这张图

技术面（工具、模型、边界）与社会面（阴影）**同场发生**，不是「先技术后人情」两段戏。

全书结构也可对上这张图：

1. **为何需要**（第 1 章）+ **协作建模与工具**（第 2–3 章）→ 建模空间里在干什么  
2. **Ingredients / 引导**（第 4–5 章）→ 工具箱怎么摆、怎么用  
3. **Ranking → 偏差 → 冲突 → 决策 → 极性**（第 6–10 章）→ 阴影谱系  
4. **记录、传播、活文档**（第 11 章）+ **设计之外 / 到代码**（第 12 章）→ 决策落地与环  

附录不是新技法，而是提醒：**可持续决策 = 模型推进 + 阴影被照见并可管理**；工具箱再全，若不碰阴影，场仍可能空转。
