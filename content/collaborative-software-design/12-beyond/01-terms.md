本章专名（对应原书第 12 章）。

### Customer Journey

- **中文**：客户旅程
- 从客户视角看**更整体**的体验：触点与渠道（营销、客服、线上线下员工等）。BigScreen 例：找片 → 观影 → 回家评价。常作 User Story Mapping / EventStorming / Wardley Mapping 的起点。

### User Journey

- **中文**：用户旅程
- 更偏产品设计：用户与**产品本身**交互的步骤、需要与卡点。与 Customer Journey 常被混用；书侧重点是「全旅程 vs 产品交互」。

### Impact Mapping

- **中文**：影响映射
- Gojko Adzic：用 Why（目标）→ Who（Actors）→ How（Impact / 行为变化）→ What（Deliverables）对齐故事与业务目标。利于优先级、暴露假设与认知偏差，避免「建着建着忘了要解决什么」。

### Wardley Mapping

- **中文**：沃德利映射
- Simon Wardley：先画组织景观（价值链式），再加气候模式、Doctrine，再决策——对标「没棋盘就下棋」的空战略。可与 DDD、Team Topologies 联用（见 Susanne Kaiser 等）；纵轴起步常称 value chain / user needs mapping；横轴为演化阶段（Genesis → Custom → Product → Commodity）。

### Stressor Analysis

- **中文**：压力源分析（残差理论 / residuality）
- 识别未知未来中系统未设计应对的 **stressor** → 影响 → 检测 → 缓解。**禁止按概率筛选**；多 stressor 常收敛到同一 **attractor**（缓解模式），可当气候模式输入韧性设计。

### Team Topologies

- **中文**：团队拓扑
- Skelton & Pais：按流与**认知负荷**设计团队与交互（含 stream-aligned、enabling、as-a-service 等）。书当作协作建模工具：随业务变动态调团队，而不是贴一次标签了事；与限界上下文 / 价值流对齐。

### Maturity Mapping

- **中文**：成熟度映射（Burgauer & McDermott）
- Wardley 变体：把能力当实践，沿 Novel → Emerging → Good → Best 演化；顶锚是团队要解的业务问题。比静态技能矩阵更贴语境，可指导实验、文档化、招人 / enabling team。
