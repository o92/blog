各篇结构类似：**Company Background → Problem → Discovering the Solution → Results**。阅读时盯三问：团队拿到的是问题还是功能？发现如何降低浪费？结果如何度量？

| 故事 | 笔记阅读焦点 |
|--|--|
| **Almosafer** | 能力组合与发现如何对准真实旅行场景问题 |
| **Carmax** | 规模车商场景下的赋能与结果 |
| **Gympass** | 伙伴/福利类产品中的协作与发现 |
| **Datasite（创新篇）** | 与转型长篇互补的产品创新切片 |
| **Kaiser Permanente** | 高度监管与复杂干系人环境下的产品模型 |
| **Trainline（创新篇）** | 与 PART 长篇转型叙事对照的产品创新点 |

细节以原书为准；笔记强调可迁移原则而非行业八卦。
