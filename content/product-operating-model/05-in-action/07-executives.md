书中用若干主题刻画与高管的健康关系：

| 主题 | 要点 |
|--|--|
| **Decisions** | 哪些决定在团队、哪些必须上高管；避免一切升级 |
| **Outcomes** | 用结果对话，而不是功能清单审查 |
| **Disagreements** | 允许基于证据的争论 |
| **Promises** | 对外承诺与发现现实一致 |
| **Surprises** | 无意外管理：坏消息早讲 |
| **Trust** | 长期复利；一次大翻车可毁掉试点 |

CEO/高管若只在治理会上要日期，文化信号会压过一切培训。
